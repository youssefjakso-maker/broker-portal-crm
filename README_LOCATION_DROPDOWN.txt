V13 PATCH — CLIENT LOCATION DROPDOWN + RES UNIT CATEGORY

- Preferred Location is now a dropdown on both Add Client and Edit Client.
- Options are generated from the currently published Excel inventory and active Admin-created units.
- Empty choice means Any area. No Info / blank locations are excluded.
- Existing saved locations are preserved in the Edit Client dropdown even if they are no longer in current inventory.
- Sheikh Zayed and New Zayed remain separate. October and New October also remain separate.
- The source workbook's RES value is matched as Residential (RES), not silently equated to Apartment. Use Residential (RES) when the source inventory is tagged RES.
- Apartment remains a separate exact type for records that are actually labelled Apartment.
